# BSS website and offer journey
Reference: Russell Brunson, The 3 Core Funnels, supplied by owner, pp. 10–12, 49–61, 63.
## Application to BSS
This is an adaptation of value-first acquisition, a soft implementation invitation, evidence, application and call preparation. It is not a claim that Russell personally approved the site.
- Home: primary free-guide entry; direct route for implementation-ready visitors; ordered service progression.
- Free guide -> guide-ready: immediate resource delivery before optional invitation.
- Guide-ready -> business-systems: flagship implementation sales/application entry.
- Assessment ($250): optional paid diagnostic; recommendations -> separately scoped implementation.
- Digital build (from $100 supplied-content asset): supporting service, not a downloadable product or checkout tripwire.
- Implementation (from $1,000): intake -> free video discovery -> tailored scope/price -> onboarding.
- Systems Care (from $500/month): optional implementation add-on.
- Project intake links to call-preparation; existing form and booking flow preserved.
- workflow-implementation aliases canonical business-systems; retired growth/idea URLs redirect there.
## Deliberate limits
No invented testimonials, income claims, urgency, paid digital products, checkout bumps or webinar. PDF's tripwire is a purchase funnel; free email opt-in is not that purchase funnel. Visitors need not buy each stage.
Real example shown: BSS signup -> Notion -> Gmail -> download. It demonstrates automation, not AI or client ROI.
Client result videos/case studies and founder video are not available and were not fabricated.
Consent-based marketing follow-up remains a separate unfinished operational step. Current automation delivers the guide only; no nurture sequence has been activated by this website change.
## Technical preservation
Guide form names, endpoint, consent semantics, honeypot, signup JS, Notion/Gmail automation and PDF untouched. No credentials introduced.
